# Frontend

React + TypeScript single-page app for the expense tracker, built with Vite.

| Command                 | What it does                                                          |
| ----------------------- | --------------------------------------------------------------------- |
| `npm run dev`           | Start the dev server on http://localhost:5173 (API calls go to :8080) |
| `npm test`              | Run the tests once                                                    |
| `npm run test:watch`    | Re-run the tests every time you save                                  |
| `npm run test:coverage` | Run the tests once and write a coverage report to `coverage/`         |
| `npm run lint`          | Check the code with ESLint                                            |
| `npm run format`        | Format the code with Prettier                                         |
| `npm run build`         | Type-check and build for production                                   |
